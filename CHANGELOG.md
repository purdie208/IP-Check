# Changelog

## 1.1.0 - 2026-11-09

### Added
- **Copy for Discord** button: copies a Discord-formatted summary with a colored status heading, bold labels, ✅/⚠️/❌ markers, a clickable map link (no embed preview) and small-text source details.
- Text from the Employee and Stated location fields is escaped so names with `_`, `*` and similar characters display exactly as typed in Discord.

## 1.0.0 - 2026-10-27

### Added
- First release: VPN / proxy / Tor / Private Relay / datacenter detection across proxycheck.io, vpnapi.io, IPQualityScore, ip-api.com and ipwho.is.
- Approximate geolocation with source agreement and an OpenStreetMap button.
- Distance check against a stated city or ZIP with a configurable mile limit.
- ISP, organization, ASN and connection type.
- Plain-text **Copy report**, local CSV history, and encrypted API key storage.
- Windows 11 styling with automatic light / dark mode.
